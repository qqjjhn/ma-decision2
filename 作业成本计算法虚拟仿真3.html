七、知识点注释（9.1 – 9.4）

9.1 作业成本计算法概述：为什么需要 ABC

产生背景：①直接人工比重持续下降、制造费用比重上升；②产品/客户多样化，间接费用与产量不再成比例；③自动化与信息化使小批量、多批次生产成为常态。此时用单一产量类基础分配制造费用，会系统性扭曲产品成本。

核心命题：作业消耗资源，产品消耗作业。成本不是"被生产出来的"，而是"被一系列作业驱动出来的"。

基本概念：

  • 资源：执行作业所耗费的经济代价（薪酬、折旧、动力、耗材）。
  • 作业：组织内为达到目的而进行的、消耗资源的工作单元（备料、质检、机时、包装）。
  • 作业中心 / 成本库：若干同质作业归集而成的一个成本集合，共享同一成本动因。
  • 成本动因：导致成本发生的驱动因素。分资源动因（资源→作业）与作业动因（作业→产品）。
  • 成本对象：需要计量成本的客体——本课件为产品 A、产品 B。

本课件对应：资源池（5 类资源项目，¥300,000）→ 4 个作业中心 → 产品 A / B。

9.2 基本原理：两阶段分配与“成本分配观 + 过程观”

第一阶段（资源 → 作业）：按资源动因把资源费用归集到各作业中心，形成作业成本池。如：检验耗材按检验批次归集到质检作业。

第二阶段（作业 → 产品）：按作业动因把作业成本分配到产品：

动因分配率 = 作业中心成本 ÷ 该作业动因总量
某产品应分配的作业成本 = 动因分配率 × 该产品耗用的动因量

与传统法的根本差异：传统法是"资源 → 部门 → 产品"的单阶段分摊，通常只用一个产量类基础（机器小时、人工工时、产量）；作业成本法是"资源 → 作业 → 产品"的两阶段多基础分摊，成本追溯路径更贴近因果。

两维视图：成本分配观（纵向，回答"成本是多少"）与过程观（横向，回答"为什么发生、作业是否增值"）。后者通向作业管理（ABM）与流程改进。

本课件对应：流程图中，左侧箭头为第一阶段（资源动因），右侧八条箭头为第二阶段（作业动因 × 2 个产品）。

9.3 基本程序：六步走
  1. 确认与划分作业，建立作业中心（同质作业合并；动因相同才可合并）。本车间：备料、质检、机时、包装。
  2. 归集资源费用到作业中心，形成成本池（用资源动因）。
  3. 为每个作业中心选择成本动因——三原则：与成本相关性强、可计量、能激励正确行为。
  4. 计算动因分配率：作业成本池 ÷ 动因实际总量。
  5. 按耗用量分配到各成本对象，汇总得产品制造费用。
  6. 计算产品总成本与单位成本：直接材料 + 直接人工 + 分配的制造费用。

关键提醒：直接成本（直接材料、直接人工）可直接追溯，不参与分摊；只有间接费用才需要分配。本课件中，A 的直接成本 ¥150,000、B 的直接成本 ¥58,000 都是直接追溯的。

9.4 与传统成本法的比较：成本扭曲与决策后果

扭曲机理：传统法用单一基础分配，隐含"制造费用与机器小时（或人工、产量）同比例发生"。当产品批量、工艺复杂度、批次与检验频次差异大时，非产量类作业（备料、质检、换产）的成本被产量类基础"平均化"。

  • 大批量、工艺简单的产品：耗用非产量作业少，却被按高产量摊了大量费用 → 成本被高估。
  • 小批量、多批次、工艺复杂的产品：耗用非产量作业多，却摊得少 → 成本被低估。

结果就是交叉补贴：A 在"补贴" B。

决策后果：

  • 被高估的产品 → 定价偏高，丧失价格竞争力与市场份额；或被误判为亏损而错误停产、外包。
  • 被低估的产品 → 定价偏低，"账面盈利、实则亏损"，卖得越多亏得越多；且容易过度占用产能。
  • 错误的产品组合、客户盈利分析与自制/外购决策。

ABC 的局限：①实施与维护成本高，需要大量动因数据；②动因选择带有主观性，选择不当同样会扭曲；③部分成本（如厂房折旧、厂部管理）仍难找到合理动因，需"维持性作业成本"处理；④主要服务于内部管理决策，通常不直接用于对外财务报告的成本计量。

思考题：①如果把"备料"的动因由备料次数改为原料重量，A、B 成本会怎样变化？②当 B 的产量提升到 5,000 箱，扭曲会消失吗？为什么？③哪些动因既能准确分配成本，又能引导车间减少不增值作业？
