知识点5.1 – 5.5 注释

按教材第 5 章（经营决策）体例整理，供课堂讲解与课后自学对照。

5.1 经营决策基础：相关成本与三种基本方法

一、相关成本 vs 无关成本

  • 相关成本：随方案改变而改变、且为未来发生的成本。包括变动成本、追加的专属固定成本、机会成本、可避免成本、重置成本、付现成本。
  • 无关成本：不随方案改变而改变。典型是沉没成本（已发生、无法回收）与共同固定成本（多个方案共同负担）。
  • 判断口诀：「两方案都要花的，不相关；只有某一方案才花的，才相关」。

二、三种基本方法

  1. 差量分析法：比较两方案的差量收入与差量成本，Δ利润 = Δ收入 − Δ成本 > 0 则取前者。用于深加工、特殊订单、自制或外购等两两比较。
  2. 贡献边际分析法：存在剩余产能且不增加固定成本时，只要单位贡献边际 > 0（或贡献边际总额 > 0），方案即可取。
  3. 成本无差别点法：求两方案总成本（或总利润）相等的业务量 Q*，业务量大于 Q* 取某一方案、小于则取另一方案。用于存在专属固定成本的场景（如本课件 5.3）。

三、决策流程：明确决策目标 → 列举备选方案 → 识别相关成本与相关收入 → 定量比较（差量/贡献边际/无差别点）→ 叠加定性因素 → 形成结论。

四、常见错误：① 把单位固定成本计入差量（固定成本在相关范围内不随产量变动）；② 忽略机会成本（挤占正常销售、占用资源的潜在收益）；③ 用「单位成本」而非「相关成本」比较。

5.2 品种决策：单位约束资源贡献边际

判据：只有一种资源受限（其余资源充足、且产品可自由增产）时，优先安排 单位约束资源贡献边际 = 单位贡献边际 ÷ 单位约束资源耗用量 最大的品种。

为什么不是单位贡献边际：单位贡献边际高的产品往往消耗更多约束资源；真正要最大化的是「每单位稀缺资源能换回多少贡献边际」。

本课件情景：土地受限 → C 果干最优（3,600 元/亩）；人工受限 → B 罐头最优（140 元/小时）；设备受限 → A 鲜穗最优（300 元/台时）。约束不同，结论不同，这正是单一资源法的局限。

多约束并存：必须建立线性规划模型（见 5.5），用图解法或单纯形法求整体最优，不能逐个资源排序。

5.3 深加工决策：半成品是否进一步加工

核心口径：加工前已发生的成本（鲜穗种植成本、共同固定成本）是沉没/共同成本，两方案共有，不进入比较。

公式：

  • 差量收入 = 加工后销售收入 − 直接出售收入
  • 差量成本 = 追加变动加工成本 + 专属固定成本（如新增设备租金、烘干线承租费）
  • 差量利润 = 差量收入 − 差量成本；> 0 则应深加工
  • 临界产量 Q* = 专属固定成本 ÷ (单位差量收入 − 单位追加变动成本)

本课件默认数据：每吨鲜穗差量收入 3,900 元、追加变动加工成本 1,500 元、专属固定成本 20 万元 → Q* = 83.33 吨。产量 60 吨时差量利润 −5.6 万元（宜直售）；产量提到 100 吨时差量利润 +4 万元（宜加工）。

易错点：把鲜穗的种植成本 2,400 元/吨计入「差量成本」——它在两种方案下都发生，属于无关成本。

5.4 特殊订单决策：低价追加订货

适用前提：① 有剩余产能；② 不影响原有正常售价与渠道；③ 无需新增长期产能投资。

公式：

  • 差量收入 = 客户报价 × 订单量
  • 差量成本 = 单位变动成本 × 订单量 + 专属追加成本 + 机会成本
  • 机会成本 = 挤占的正常销量 × 单位贡献边际（正常售价 − 单位变动成本）
  • 保本报价 = 差量成本 ÷ 订单量

判断：报价 > 保本报价即可接受；特别地，在剩余产能范围内时，底线是报价 > 单位变动成本。

本课件默认数据：产能 300 吨、已接 200 吨、剩余 100 吨；报价 2,900 元/吨、订单 60 吨 → 差量收入 17.4 万、差量成本 14.4 万、差量利润 +3 万元，保本报价 2,400 元/吨 → 接受。

易错点：① 用「报价低于正常售价」直接拒绝（忽略了闲置产能只追加变动成本）；② 忘记挤占正常销量带来的机会成本；③ 把不可避免的固定成本摊进差量成本。

5.5 产品组合决策：线性规划图解法

建模：决策变量 x₁、x₂（各产品产量）；目标函数 max Z = Σ(cmᵢ·xᵢ)；约束 Σ(aᵢⱼ·xᵢ) ≤ 资源上限 bⱼ，以及市场容量与 x ≥ 0。

图解法步骤：① 画各约束直线；② 确定可行域（公共满足区域，凸多边形）；③ 画出目标函数等值线（等贡献边际线）并沿法向平移；④ 最后一个离开可行域的接触点即最优解——必为可行域顶点。

顶点定理：线性规划若有最优解，必可在可行域的某个顶点上取得。因此只需枚举顶点（本课件枚举所有约束两两交点后筛可行点），再取 Z 最大者。

松弛与影子价格：松弛量 = 上限 − 实际耗用；为 0 者为紧约束，其影子价格 > 0，是扩产优先解瓶颈；松弛量大者短期不必追加投入。

本课件默认（B 罐头为 x、A 鲜穗为 y）：最优 x = 170.7 吨（罐头）、y = 195.1 吨（鲜穗），Z ≈ 71.22 万元；土地与设备为紧约束（松弛量 0），人工约 244 小时松弛、两端市场容量均未用满。切换到 A+C 组合可得 Z = 67.20 万元（最优 200, 60），B+C 组合约 71.63 万元（最优 101.5, 60）——可据此讨论「组合整体最优 ≠ 单品种排序最优」。
