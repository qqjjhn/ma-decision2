💡 什么是数据离散程度？ ▼

数据离散程度：指各个数据点偏离回归线（整体趋势）的远近程度。

📊 离散程度低：数据点紧密围绕回归线，说明产量和电费的关系很稳定，R²接近1。比如湘农机械如果每月电费只受产量影响，不受气温、设备等因素干扰，离散程度就低。

📊 离散程度高：数据点散乱分布，说明除了产量外还有其他因素影响电费（如极端高温、设备故障、春节放假），R²较低。

👉 拖动上方"数据离散程度"滑块，直观感受从低到高时散点从"集中"变"散乱"、R²从0.95降到0.4的过程。

💡 什么是异常点？ ▼

异常点（Outlier）：指明显偏离整体数据趋势、与其他数据点"格格不入"的观测值。

🔴 湘农机械的两个异常点：

• 8月：产量1150件，但电费高达16800元（全年最高）——极端高温导致空调用电大增，电费偏离了"产量越高电费越高"的正常趋势。

• 2月：产量850件，但电费仅11800元（全年最低）——春节放假，生产用电少，但基本电费照付，导致电费偏低。

⚠️ 异常点的影响：会拉偏回归线，使计算出的固定成本a和单位变动成本b失真。剔除异常点后，模型更能反映正常经营状态下的成本规律。

👉 拖动上方"剔除异常点数量"滑块：1=剔除8月，2=同时剔除8月和2月，观察R²和回归线的变化。

⚠ 数据已被篡改！观察两条回归线的偏移

演示目的：假设财务人员将5月电费从14200元虚增至17040元（+20%），声称"五一后设备重启用电增加"。图中红色虚线是原始回归线，橙色实线是篡改后的回归线——仅一个数据点的变动，就使整条回归线发生明显偏移，固定成本a和单位变动成本b都被扭曲。

教学启示：这就是"垃圾进、垃圾出"。会计数据真实性是一切分析的基础，一个数据点的偏差会导致成本预测、定价决策的系统性错误。不做假账，是会计人的职业底线。

⚖️三种混合成本分解方法对比
点击方法名称可展开详细说明。
方法基本原理优点缺点适用条件精确度
高低点法 ▸ 选业务量最高最低两点，连线确定y=a+bx 计算简单，易于理解 仅用两点，代表性差 成本趋势稳定，数据少 较低
详细说明：高低点法是最基础的混合成本分解方法。
步骤：①按业务量（不是成本！）选择最高点和最低点；②计算单位变动成本 b=(高成本-低成本)/(高业务量-低业务量)；③计算固定成本 a=高成本-b×高业务量；④建立成本模型 y=a+bx。
湘农机械案例结果（正确选点）：高点(1200件,15800元)，低点(800件,12500元)，b=8.25元/件，a=5900元，模型 y=5900+8.25x。
易错点：必须按业务量选点！湘农机械中按成本选点会得出 b≈16.67、a≈-2370（负固定成本，不合理！）。
散布图法 ▸ 全部数据点入坐标系，目测画线 考虑全部数据，直观 目测主观，因人而异 精度要求不高，快速估算 中等
详细说明：散布图法将全部历史数据点绘入坐标系，然后通过目测画一条最接近所有数据点的直线。直线与纵轴交点为固定成本a，斜率为单位变动成本b。
优点：考虑全部数据点，比高低点法更全面；图形直观，便于发现异常值。
缺点：画线依赖目测，主观性强，不同人画的线可能不同。
实务中：常用于初步分析或数据探索阶段，正式决策一般用回归法。
回归直线法 ▸ 最小二乘法，误差平方和最小 理论最完善，结果最精确 计算复杂，需软件 数据量大，线性相关度高 较高
详细说明：回归直线法运用最小二乘法原理，使所有数据点到回归直线的误差平方和最小，从而确定唯一的最优直线。
Excel操作：①加载"分析工具库"（文件→选项→加载项→转到→勾选）；②数据→数据分析→回归；③Y值选成本列，X值选业务量列；④查看输出。
关键输出：Intercept=固定成本a；X Variable 1=单位变动成本b；R Square=拟合优度（越接近1越好）。
湘农机械案例结果：a≈2380元，b≈12.1元/件，R²≈0.95（线性关系强）。
注意：若R²<0.5，说明线性关系弱，需考虑非线性模型或增加其他自变量（如气温、设备工时等）。

练习一：高低点法分解混合成本

📝 题目

某企业2025年上半年维修费与产量数据如下：

月份1月2月3月4月5月6月
产量(件)100120150180200160
维修费(元)220024002700300032002800

要求：用高低点法将维修费分解为固定成本和变动成本，建立成本模型，并预测产量为220件时的维修费总额。

💡 提示：先找业务量（产量）的最高点和最低点，注意不是按维修费选点！

✅ 答案与解析

第一步：选点（按产量）

高点：5月，产量200件，维修费3200元

低点：1月，产量100件，维修费2200元

第二步：计算单位变动成本 b

b = (3200 - 2200) / (200 - 100) = 1000 / 100 = 10 元/件

第三步：计算固定成本 a

a = 3200 - 10×200 = 3200 - 2000 = 1200 元

第四步：建立成本模型

y = 1200 + 10x

第五步：预测产量220件时的维修费

y = 1200 + 10×220 = 1200 + 2200 = 3400 元

练习二：回归分析结果解读

📝 题目

某企业用Excel回归分析工具，得到电费（Y）与产量（X）的回归结果如下：

• Intercept（截距）= 3500

• X Variable 1（X系数）= 8.5

• R Square（决定系数）= 0.92

要求：① 写出成本模型；② 解释R²=0.92的含义；③ 预测产量为500件时的电费。

✅ 答案与解析

① 成本模型

固定成本 a = Intercept = 3500元

单位变动成本 b = X Variable 1 = 8.5元/件

y = 3500 + 8.5x

② R²=0.92的含义

R²=0.92表示产量可以解释92%的电费变动，线性关系很强，回归结果可靠。剩余8%的电费变动由其他因素（如季节、设备老化等）解释。

③ 预测产量500件时的电费

y = 3500 + 8.5×500 = 3500 + 4250 = 7750 元
